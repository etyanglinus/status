How we monitor Fasta

Every minute, automated checks run from Cloudflare's network, separate from Fasta's own servers, so this page keeps working even if Fasta is down. Checks look at real content: a page that loads but shows an error or maintenance screen counts as a failure.

  • Operational: all checks for the service are passing.
  • Degraded performance: the service works but has been responding slowly (over 5 seconds) for 3 minutes or more.
  • Partial outage: some of the service's checks have failed 3 times in a row.
  • Major outage: all of the service's checks have failed 3 times in a row.
  • Scheduled maintenance: planned work announced in advance.
  • Status unavailable: we haven't received fresh results for 3 minutes, so we can't confirm the current state.
  • No known issues: automated checks aren't live yet for this service; the Fasta team updates it by hand.

A single failed check never changes the status; it takes 3 failures in a row. A service counts as recovered after 2 successful checks in a row. The Fasta team posts incident updates with what's affected, what still works and when to expect the next update. All times are East Africa Time (EAT).
